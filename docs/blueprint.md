# **App Name**: Wena Einstien?

## Core Features:

- Category Display: Browse available quiz categories with appealing visuals.
- Quiz Interface: Present questions in a clear format and capture user responses.
- Instant Feedback: Show the user results immediately with feedback on correct/incorrect.
- AI Score Analysis: Offer customized tips to improve future scores, using the LLM as a tool.

## Style Guidelines:

- Primary color: Vibrant yellow (#FFC72C) evoking energy and optimism, drawing inspiration from South African vibrancy.
- Background color: Light beige (#F5F5DC), a desaturated hue close to the primary yellow, providing a warm and unobtrusive backdrop.
- Accent color: Muted orange (#D98E2A), an analogous color to yellow that complements the primary color while adding depth and visual interest.
- Font: 'PT Sans', a humanist sans-serif providing a modern and readable feel, suitable for both headings and body text.
- Use icons which clearly represent South African cultural elements.
- Prioritize a mobile-first, clean design with easily navigable quiz categories.
- Use animations during key events like score updates.
